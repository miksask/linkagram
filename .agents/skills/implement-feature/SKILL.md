# Implement Feature

When asked to implement a feature:

1. Read `AGENTS.md`.
2. Read the matching spec in `docs/specs/`.
3. Inspect existing implementation before proposing changes.
4. Produce a concise plan.
5. Identify edge cases and security implications.
6. Implement the smallest coherent solution.
7. Add or update tests.
8. Run Gradle checks if `./gradlew` exists; otherwise state that checks are unavailable.
9. Summarize:
   - what changed;
   - assumptions made;
   - commands run;
   - known limitations.
